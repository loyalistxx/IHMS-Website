# Integrated Healthcare Management System (IHMS) 🏥

نظام متكامل لإدارة الرعاية الصحية تم تطويره كـ **مشروع تخرج** لبرنامج نظم معلومات الأعمال (BIS) بمعهد العبور العالي للحاسبات والإدارة ونظم المعلومات.

## 📑 نبذة عن المشروع
يهدف النظام إلى أتمتة العمليات الإدارية والطبية داخل المستشفيات، وربط جداول المرضى والمواعيد والمخزون في منصة واحدة لضمان كفاءة العمل وتقليل الأخطاء البشرية.

## 🚀 الميزات الرئيسية
* **لوحة تحكم الأدمن (Admin Dashboard):** عرض إحصائيات فورية لإجمالي المرضى، مواعيد اليوم، ونواقص المخزون.
* **إدارة المرضى:** تسجيل كامل لبيانات المرضى، التاريخ الطبي، وفصائل الدم.
* **نظام المواعيد الذكي:** حجز وتعديل المواعيد مع تحديث تلقائي لتاريخ آخر زيارة للمريض عند إتمام الكشف.
* **تكامل المخزون (ERP Logic):** خصم تلقائي للمستلزمات الطبية من المخزون عند تأكيد الكشف على المريض.
* **بوابة المريض (Patient Portal):** تتيح للمرضى حجز المواعيد ومراجعة ملفاتهم الشخصية وتاريخ زياراتهم.

## 🛠 التكنولوجيا المستخدمة (Tech Stack)
* **Backend:** Python (Flask Framework).
* **Database:** Microsoft SQL Server (MSSQL).
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript.
* **Database Connectivity:** PyODBC.
* **Data Simulation:** Faker Library (لإنشاء بيانات وهمية واقعية).

## 💻 المتطلبات التشغيلية
لتركيب وتشغيل المشروع محلياً، تأكد من تثبيت:
* Python 3.x
* Microsoft SQL Server
* ODBC Driver 17 for SQL Server

## 🔧 خطوات التشغيل
1.  **تحميل المشروع:**
    ```bash
    git clone [https://github.com/YourUsername/IHMS-Project.git](https://github.com/YourUsername/IHMS-Project.git)
    cd IHMS-Project
    ```
2.  **تثبيت المكتبات اللازمة:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **إعداد قاعدة البيانات:**
    * قم بإنشاء قاعدة بيانات باسم `IHMS`.
    * قم بتعديل الـ `conn_str` في ملف `app.py` ليتوافق مع اسم السيرفر الخاص بك.
4.  **ملء البيانات (اختياري):**
    * قم بتشغيل سكربت البيانات الوهمية: `python fill_data.py`.
5.  **تشغيل السيرفر:**
    ```bash
    python app.py
    ```
